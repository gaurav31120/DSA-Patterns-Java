* Solve the **Pratyush problems first** for each pattern.
* After completing a Pratyush pattern, solve the **additional problems selected separately** for that pattern.
* Avoid unnecessary duplicate problems.
* Focus on understanding patterns and techniques rather than only counting problems.
* Practice every meaningful approach where applicable.
* Maintain clean Java implementations.
* Document every completed problem with `Problem.md` and `Approaches.md`.
* Commit and push each completed approach independently.
