# P002 — Start of Linked List Cycle

## Pattern

Fast & Slow Pointers

## Difficulty

Medium

## LeetCode

**#142 — Linked List Cycle II**

## Problem

Given the head of a singly linked list, return the node where the cycle begins.

If there is no cycle, return `null`.

A cycle exists if a node in the linked list can be reached again by continuously following the `next` pointer.

You must return the actual node where the cycle begins, not its value.
